# Angello Ascend

Crée un site web premium, professionnel et responsive pour "ANGELLO School" (Groupe Scolaire Bilingue Angello), un établissement scolaire privé situé à Japoma, Douala, Cameroun.

CONTEXTE

École bilingue (Français/Anglais) créée en 2023

Niveaux : Crèche, Garderie, Maternelle, Primaire

500+ élèves, 25 enseignants qualifiés

100% de réussite au CEP depuis 3 ans

95% de satisfaction parentale

3 bus de transport haut standing

Activités périscolaires : sports (football, handball, natation), arts (musique, danse, dessin, théâtre), robotique/coding, clubs de lecture, jardinage, élevage, langues supplémentaires.

DESIGN SYSTEM

Palette de couleurs :

Primaire : Bleu marine profond  #1e3a8a 

Secondaire : Or/Doré  #fbbf24 

Fond : Blanc pur  #ffffff  / Gris très clair  #f8fafc 

Texte : Gris foncé  #1f2937  (principal), Gris moyen  #6b7280  (secondaire)

Typographie :

Titres (H1, H2, H3) :  Playfair Display  (serif élégant)

Corps de texte :  Inter  ou  Poppins  (sans-serif moderne)

Accents : Gras pour les chiffres clés.

Style visuel :

Design épuré avec beaucoup d'espace blanc (whitespace).

Cards avec ombres subtiles ( shadow-md ,  hover:shadow-lg ).

Bordures arrondies ( rounded-lg ,  rounded-xl ).

Animations fluides au scroll (fade-in, slide-up).

Effet de lumière (shimmer/glow) au survol des boutons principaux.

Transitions douces ( transition-all duration-300 ).

STRUCTURE DU SITE (PAGE D'ACCUEIL)

1. HEADER (Navigation)

Logo "ANGELLO School" à gauche, suivi du nom en toutes lettres.

Menu : Accueil | À Propos | Vie Scolaire | Contact

Bouton CTA principal : "Préinscrire mon enfant" (fond bleu, texte blanc, hover: fond or).

Bouton secondaire : "Télécharger la brochure" (outline bleu).

Menu hamburger pour mobile.

Style : Effet glassmorphism premium et léger (backdrop-blur) sur le header au scroll.

2. HERO SECTION

Layout : Texte à gauche, image à droite sur Desktop. Empilement vertical (texte en haut, image en bas) sur Mobile.

Image : Placeholder haute qualité (enfants africains souriants en uniforme dans une cour d'école moderne).

Phrase d'accroche : "À Angello, vos enfants apprennent deux langues. Mais surtout, ils apprennent à grandir."

Sous-titre : "École bilingue d'excellence à Douala - 100% de réussite au CEP depuis 3 ans."

Boutons CTA :

1.

"Préinscrire mon enfant" (primaire, bleu)

2.

"Découvrir notre école" (secondaire, outline blanc)

3. SECTION CHIFFRES CLÉS (Animations)

Fond bleu marine, texte blanc, icônes dorées (SVG, pas d'emojis).

4 cards au design épuré (inspiré Pinterest) avec animation de comptage (count-up) au scroll :

🎓 (Icône diplôme) : 500+ élèves épanouis

🏆 (Icône trophée) : 100% de réussite au CEP (3 ans)

👨‍🏫 (Icône enseignant) : 25 enseignants qualifiés

🚌 (Icône bus) : 3 bus de transport

4. SECTION "POURQUOI ANGELLO ?"

Titre : "Ce qui nous distingue"

Grille de 6 cards professionnelles (3x2 sur desktop, 2x3 sur tablette, 1x6 sur mobile).

Chaque card : icône SVG dorée, titre, description courte.

Contenu : Excellence académique, Bilinguisme réel, Activités périscolaires variées (5+), Transport sécurisé, Équipe passionnée, Environnement bienveillant.

Animation : apparition au scroll avec délai progressif (staggered fade-in).

5. SECTION NOS NIVEAUX (Timeline)

Titre : "Un parcours éducatif complet"

Layout Responsive :

Desktop (PC) : Timeline horizontale progressive de gauche à droite, avec une ligne centrale dorée reliant les étapes.

Mobile : Timeline verticale avec la ligne dorée à gauche et les étapes qui s'empilent.

4 étapes (Crèche, Garderie, Maternelle, Primaire) avec pour chacune : numéro, icône, titre, description courte, et bouton "En savoir plus".

Animation : la ligne se dessine au scroll + apparition progressive des étapes.

6. SECTION ACTIVITÉS PÉRISCOLAIRES

Titre : "Au-delà des cours"

Grille de 7 cards professionnelles (icônes SVG + titre, aucun emoji) :

Sports (football, handball, natation)

Arts (musique, danse, dessin, théâtre)

Robotique & Coding

Clubs de lecture

Jardinage & Agriculture

Élevage

Langues supplémentaires

Design : cards avec fond léger, bordure subtile, et effet hover élégant.

7. SECTION TRANSPORT

Titre : "Transport scolaire sécurisé"

Layout : image à gauche (bus scolaire moderne), texte à droite.

Points clés : Flotte de 3 bus haut standing, chauffeurs qualifiés, couverture étendue à Douala, sécurité maximale.

Bouton CTA : "En savoir plus sur le transport" → ouvre un modal ou redirige vers WhatsApp avec message pré-rempli : "Bonjour ANGELLO School, je souhaite obtenir des informations sur le transport scolaire. Merci."

8. SECTION TÉMOIGNAGES (Carousel)

Titre : "Ils nous font confiance"

Carousel automatique (change toutes les 5 secondes) + navigation manuelle (flèches + dots).

4 témoignages de parents : Photo (placeholder), Nom, "Parent de [X], classe de [Y]", Citation.

Design : cards blanches avec ombre, guillemets dorés en arrière-plan, parfaitement responsive.

9. SECTION GALERIE (Masonry + Lightbox)

Titre : "La vie à Angello en images"

Grille masonry (3 colonnes desktop, 2 tablette, 1 mobile).

Comportement : Afficher 6 photos initialement. Un bouton élégant "Voir plus de photos" révèle les 9 photos restantes (total 15) avec une animation smooth.

Lightbox : clic sur image → ouverture plein écran avec navigation (flèches + close).

Animation : fade-in au scroll.

10. SECTION APPEL À L'ACTION

Fond : dégradé bleu marine vers bleu plus clair.

Titre : "Prêt à rejoindre la famille Angello ?"

Sous-titre : "Inscrivez votre enfant dès maintenant et offrez-lui un avenir brillant."

Deux boutons : "Préinscrire mon enfant" (fond or, texte bleu) et "Télécharger la brochure" (outline blanc).

4 colonnes :

Logo ANGELLO + description courte + réseaux sociaux (Facebook, LinkedIn, WhatsApp avec icônes SVG).

Liens rapides (À Propos, Vie Scolaire, Contact, Préinscription).

3.

Contact (Adresse : Japoma, Douala | Téléphone : +237 678 50 99 42 | Email : contact@angello-school.com).

Bottom bar : © 2026 ANGELLO School. Tous droits réservés. | Mentions légales | Politique de confidentialité

FONCTIONNALITÉS TECHNIQUES

Bouton WhatsApp Flottant : Fixed, bottom-right (20px), icône verte (#25D366) avec animation pulse. Au clic, ouvre WhatsApp (+237 678 50 99 42) avec le message : "Bonjour ANGELLO School, je souhaite obtenir des informations. Merci."

Animations : Fade-in au scroll, slide-up pour les cards, comptage animé, hover effects, effet de lumière (shimmer) sur les boutons principaux.

Responsive Design : Mobile-first, breakpoints (sm: 640px, md: 768px, lg: 1024px, xl: 1280px), menu hamburger, grilles adaptatives.

SEO & Performance : Balises meta, structure sémantique, alt text sur images, lazy loading, format WebP.

Icônes : Utiliser exclusivement des icônes SVG professionnelles (ex: Lucide React ou Heroicons), aucun emoji dans le rendu final.
